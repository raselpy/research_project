# research_project

Reproduction of Isensee et al., *"nnU-Net for Brain Tumor Segmentation"*
(BraTS 2020 winner, arXiv:2011.00848), built in strict sequential phases
per the project's Build Planner. See the planner document for the full
phase-by-phase spec, acceptance checks, and the thesis extension
(Phases 10-11: uncertainty-calibrated, rank-aware postprocessing).

**Status:** Phase 0 (repo bootstrap) in progress.
